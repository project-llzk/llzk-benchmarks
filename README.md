# llzk-benchmarks
LLZK Benchmarks provides curated, reproducible or externally linked circuit artifacts compiled through the LLZK pipeline from various zero-knowledge frameworks (Circom, Halo2, SP1, ZKM, etc.).
Some benchmarks are directly reproducible from public toolchains; others are linked to hosted artifacts (e.g., Veridise AuditHub outputs or published archives) where regeneration instructions may be private or proprietary.
